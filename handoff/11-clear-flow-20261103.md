# 11｜清晰主线与统一体验

版本：`clear-flow-20261103`，2026-11-03。本文记录当前实现，提交、构建、部署与线上核验以[发布回执](release-clear-flow-20261103.md)为准；用户授权同步代码不等同于用户最终验收。

## 入口与信息结构

主线为“选需求 → 看方案 → 整理需求”。首页首屏的两项业务选择直接到`/works?product=hall`活动互动方案或`/works?product=bespoke`影片定制方案。主导航为首页／应用方案／体验演示／合作需求。产品说明页保留为列表中的补充信息，归应用方案高亮，返回各自筛选列表。

八份方案统一为只读介绍：大图与简明定位、玩法／创作流程、成果价值、完整策划展开区、合作入口。原方案“选一选”已移除，其选项含义保留为策划参考。品牌与退休内容仍为方案示例；场景配图不是已交付案例，退休专属体验未开放，高定由团队创作并按需报价。

当前视觉为明亮背景、圆角大图、简洁导航与较多留白；深浅色切换收在更多菜单。详细准备资料、流程和产品说明按需展开，正常流程不再引向空样品状态页。

## 统一体验与需求整理

实际设定统一在模板／自定义体验中心。三步骤始终可见：**选内容 → 照片（选填） → 查看设定**。模板完整设定可展开查看，自定义仍可选择身份、场景并编辑行为。最终状态是“设定预览已完成”，保留复制配置与禁用的生成按钮；不会上传照片或创建生成任务。

模板与自定义草稿在本次浏览内独立保留，照片授权、更换照片后的重新授权、返回修改和刷新清空边界继续有效。合作入口只在体验最终页出现。

合作需求页先显示方向和需求描述，单位、时间、规模、联系人及联系方式放入选填展开区。来源可带入合法业务与方案，结果仍为本机摘要和复制，不表示已发送或已受理。

## 来源与返回

| 路径 | 预期返回 |
|---|---|
| 列表 → 方案详情 | 回相同产品筛选的方案列表 |
| 列表 → 合作需求 | `source=solutions`回活动／定制方案列表，必须显式指定合法`product` |
| 方案 → 合作需求 | `source=application`回方案详情，保留方案与列表筛选来源 |
| 方案／活动列表 → 体验 | `returnTo`经白名单规范化，模式切换保留来源 |
| 体验最终页 → 合作需求 → 体验 | `source=experience`＋受控`experienceReturn`回原模式，恢复内存步骤与草稿 |
| 无上下文体验入口 | “查看活动方案”到`/works?product=hall` |
| 产品说明页 | 回对应活动／定制方案列表 |

`experienceReturn`只接受`/experience-center`和`template`／`custom`模式，嵌套`returnTo`再次校验后由`experiencePathFor`重建。仅AI影像馆允许该体验来源；方案方向须与体验来源匹配才保留参考方案引用。只传浏览上下文，不能把配置、照片或联系方式放入地址。

路由守卫只解码路径；查询串仅校验编码，不提前解码，避免多层返回地址丢失筛选。完整参数及兼容规则见[01 页面与路由](01-product-and-routes.md)。

## 兼容与验证边界

旧九主题ID、数字详情与配置URL继续兼容，退出正常浏览入口；`/samples/hall?preview=themes`不再展示旧配置库。样片路由仍可访问，缺少正式素材时标明待上架。只有已发布且明确授权的作品才进入正式展示。

本轮内容测试覆盖首页直达、方案只读、旧入口退出、来源白名单、真实返回链接、嵌套查询编码及原内容事实。实际测试结果、浏览器走查和部署状态统一见[发布回执](release-clear-flow-20261103.md)。旧浏览器完整套件未整体迁移，未执行的照片流程、真机及用户验收项目不能视作已完成。真实生成与正式咨询承接不在本轮UI改版中接入。
