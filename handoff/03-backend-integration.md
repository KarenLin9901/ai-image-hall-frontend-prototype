## 1. 当前接入面与源码依据

| 接入面 | 目前真实实现 | 后端工作起点 |

### 新体验中心的前端数据

`#/experience-center?mode=template|custom`。新本地设定ID为`city-walk`、`brand-star`、`campus-memory`；身份、场景和行为固定，但尚无真实生成templateId。自定义模式选择本地身份ID、场景ID并填写action文本；同样尚无服务端Schema、允许组合及生成映射。

## 3. 当前前端类型：不是网络请求/响应Schema

以下为现有读模型，字段真值和可选性应以源码为准。数据库结构、后端DTO和外部接口可另行设计，但须通过适配层保持当前业务关系和缺省保护。

| 类型 | 当前字段 |
|---|---|
| `Media` | `type: 'image' \| 'video'`，`src: string`，`poster?: string`，`width/height: number`，`alt: string` |
| `Category` | `id`，`business`，`title`，`short`，`intro`，`audience`，`image: number`，`themes: string[]` |
| `ThemeRecord` | `id`，`categoryId`，`title`，`image`，`caseIds: string[]`，`templateId?: string`，`status: 'example' \| 'published'` |
| `ThemeConfiguration` | `id`，`categoryId`，`title`，`image`，`options: {title; items: string[]}[]`，`participation: '单人主角'`，`materialHint` |
| `CaseRecord` | `id/title/categoryId/themeId/background/objective`，`media: Media[]`，`status: 'draft' \| 'published'`，`displayAuthorized?: boolean` |
| `PublishedWork` | `id/title/categoryId/business`，`themeId?/caseId?/templateId?`，`media: Media`，`source`，`displayAuthorized: boolean`，`status: 'draft' \| 'published'`，`sort: number`，`publishedAt: string` |
| `EditorialPlan` | `categoryId/business/title/kicker/summary/audience/image/imageLabel/imageFormat?`，`themeId?`，`planned?`，`choices[]`（标题/示意项/含义），`journey[]`，`outcome`（标题/说明/延展），`participantValue`，`projectValue`，`preparation[]` |

当前`themes`9条均为`status: 'example'`、`caseIds: []`，未配置真实`templateId`。`templateEntries`只有`shenzhen-belike`这一条本地占位，`status: 'coming-soon'`、`url: null`；它不是可用服务入口，也不能证明其余八主题已有后端模板。

### 发布和授权的展示门槛

前端共享守卫为：`status === 'published' && displayAuthorized === true`。缺少授权字段、值为false、字符串`"true"`或数字1均不满足；已发布不等于已授权。

- 样片专区还要求`media.type === 'video'`，并按业务及可选分类筛选真实作品。
- 真实作品图库允许图片或视频；相关案例按记录级守卫展示其`media[]`。当前没有媒体条目级授权模型，须在B03确认后补足实际契约，不能把案例级布尔值当成每条媒体的授权证明。
- 参考图、概念图、场景方案与正式样片/客户案例分开。公开媒体、审核人、权利依据、有效期、撤回和下架联动需要由真实内容流程提供；前端布尔标记不能承担审核系统或访问控制职责。

## 4. 本机配置与合作需求字段

### 主题草稿

`ThemeDraft = { step: number; choices: string[]; photo: string; authorized: boolean }`。

- `choices`按本主题3组的顺序保存已选中文项；每组一项才允许进入下一步。
- `photo`是本机Object URL，不是照片文件、上传地址或服务端assetId；不能传入后台或分享链接。复制摘要只说明是否选照片，不含照片或Blob URL。
- `authorized`只是本机“已获得这张照片的使用授权”勾选。更换照片重新勾选；它不自动覆盖生成处理、公开展示或其他用途。
- 允许JPG/PNG/WebP，当前本机上限10MB，且需解码成功。检查中不能推进；坏图不替换旧有效照片；移除、重选或离页取消待验证图片并回收URL。
- 只保留当前一个主题的内存草稿；临时切页再回来可恢复，换主题有清空确认，刷新/关闭清空。当前不写localStorage/sessionStorage，也没有跨设备草稿。

这些限制是当前前端行为，不能直接推定真实生成素材必填/选填规则或服务端文件限制。若现有生成服务要求照片必填、不同格式或其他身份素材，先更新协议和产品说明，再同步前端校验。

### 合作草稿及摘要

| 字段 | 当前前端行为 |
|---|---|
| `direction` | 必选；值为分类中文标题，也可选“尚未确定，想先了解”。有产品上下文时仅显示该业务方向 |
| `description` | 必填，去首尾空白后不能为空，最多2000字符 |
| `organization` | 选填，最多100字符，单位/项目 |
| `timing` | 选填，最多100字符，自由文本；不是标准日期字段 |
| `scope` | 选填，最多160字符，人数/场次或片长/画幅等自由文本 |
| `name` | 选填，最多50字符 |
| `contact` | 选填，最多100字符；当前不要求手机号或邮箱格式 |

路由上下文为`product`（业务）、`direction`（分类ID）、`theme`（主题ID）、`source: product | application | theme | samples | chooser`、`section: experience | introduction | applications | pricing`。注意URL的direction是ID，表单direction却是中文标题；未来服务若使用分类ID，须显式映射。现有内存键为`business:categoryId:themeId`，不是后端需求单ID。体验地址的`returnTo`与产品返回的`restore=1`只表达经白名单约束的导航来源，不属于业务请求参数。

主题来源的合作需求可带本机已选文字进入摘要；页面返回和摘要复制仍不创建咨询。当前只有产品、参考主题及文字选项、用户填写字段和“尚未发送”说明，没有服务端提交结果、咨询编号或跟进状态。合法方案来源现在包含具体代表方案名；改为其他方向时页面与摘要同步取消不适用的方案引用。原有主题来源继续保留参考主题及文字选择，其不兼容方向保护不变。仍不创建正式咨询记录。

带参考主题时若用户改为不兼容方向，按钮禁用并阻止摘要，保留旧主题与草稿。跨方向究竟清除、锁定还是另作参考仍待B01决策，不由后端适配层默默选择。

## 5. 联调前必须补齐的契约表

以下均为**待提供项**；本文件不指定虚构URL、HTTP方法、鉴权头、任务状态枚举或成功响应。由产品/现有服务方确认后，前后端将实际文档地址、版本、责任人和测试环境补入同一记录。

| 能力 | 必须补充的协议内容 | 当前可推进的工程准备 |
|---|---|---|
| 内容读取 | 来源与环境、列表/详情字段、分页/排序、媒体尺寸及可访问地址、发布/授权状态、空态和下架行为 | 对照现有读模型整理映射和空值保护；区分示意内容与真实作品 |
| 模板/选项 | 真实templateId、模板版本、稳定groupId/optionId、有效组合、素材要求、开放条件、业务/分类/主题绑定 | 编制9主题映射待填表，保持现有ID和URL，未映射主题不能开放生成 |
| 上传与素材 | 是否本期、何时上传、身份和权限、文件限制、返回素材标识、用途同意、生命周期/撤回/清理、取消与失败处理 | 把本机预览与上传状态分开建模；Object URL不得当后端资源标识 |
| 生成任务 | 请求与响应、身份/权限、真实选项映射、任务创建/查询或通知方式、状态及可达转换、取消、超时、失败、重试与幂等、结果有效期 | 确认协议后才画状态机和实现请求适配；现有禁用按钮继续禁用 |
| 正式咨询 | 正式渠道及接收方、最小字段、同意要求、成功/失败回执、重复提交、记录查询与可见范围 | 复用已确认的文字字段，定义本机草稿和正式提交记录的区分 |
| 账户/订单/支付/下载/分享 | 每项是否纳入、现有服务协议、权限、异常处理、结果与订单关系、领取方式和有效期 | 只对已确认纳入的能力设计接口；不推定价格、订单状态、收费或退款政策 |
| 通用网络与发布环境 | 测试/正式来源、允许跨域与凭证方式、访问权限、请求取消、错误码/错误体、离线/超时、分页和幂等规则 | 准备适配层与可控失败测试，不能把静态图片失败覆盖当成业务请求失败已验收 |

建议映射工作表的列为“本地themeId / 真实templateId / 模板版本 / 本地组标题 / 本地选项文案 / 服务端组标识 / 服务端选项值 / 素材规则 / 启用条件 / 协议版本 / 确认人”。目前后端列保持待填，不能用展示文案代填机器值。

## 6. B01–B13交接检查表

这是业务与接口决策，不与前端P1/P2混为一类。角色说明表示需要谁参与确认，不表示已经指定负责人或承诺排期。

## 7. 推荐接入与验收顺序

1. **冻结读模型与范围。** 前后端按本文件校对业务、分类、新旧体验类型和当前未开放能力；产品/现有服务方补B01–B13中影响本期的关键项。本轮四导航、方案→咨询及通用体验分支的本地自检见最新回执；服务接入后仍需组合回归，不把静态原型或旧测试预期当作真实联调目标。
2. **先接可公开内容。** 在真实样片和授权依据到位后，校验关系、排序、比例、加载/失败/空态、未授权默认拒绝、撤回下架和错误详情恢复。保持应用方案示例、概念素材与真实作品的内容身份。
3. **逐主题确认生成映射。** 分别核对旧九主题三组单选、新两模式和活动专属选项的允许组合、素材规则、开放条件；没有真实映射的主题保持未开放。退休与高定不自动进入九主题生成链路。
4. **再接素材与任务。** 实测有效/坏图、边界大小、替换/取消/离页竞态、失效资源、权限错误、重复动作、超时和真实协议的全部状态；确认重试不会创建重复任务。具体状态名和幂等机制由协议定义；不能用本地模拟任务代替。
5. **单独验收正式咨询。** 核对最小字段、来源/参考信息、同意、回执和重复提交；失败保留可修改内容，成功可辨认实际接收状态。不能沿用“复制成功”作为“已提交”。
6. **最后开放新增业务和终端。** 账户/订单等按已确认范围独立验收；在选定真机容器检查软键盘、原生返回、刷新/恢复、媒体播放和真实接口整链路。最终用户验收单独记录。

前端可先实现可替换的数据访问和字段适配边界，并以清楚标识的测试数据验证加载/空/失败状态。协议未定时不把临时Schema、演示任务或虚构回执写进正式API文档，也不将账户/支付/订单页面补为默认需求。

外观切换和`imageFormat`属于前端展示状态，不进入业务提交参数；`imageFormat`只描述参考图自然比例，不代表影片交付画幅，B11仍需确认。
