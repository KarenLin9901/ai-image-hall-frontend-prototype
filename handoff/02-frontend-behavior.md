## 关键路径与状态转换

### 1. 产品与方案阅读

首页介绍B端用途与两产品区别。AI馆首屏“查看应用方案”定位本页`scenes`段，与页内同名导航一致；全局“应用方案”才进入完整方案库。次动作“体验产品能力”进入保留当前产品来源的通用两玩法演示；高定首屏“咨询定制”进入带产品来源的表单。AI页内导航为产品定义/应用方案/体验能力/项目合作，高定为产品介绍/创作与样品/价格说明/咨询定制。高定 `section=pricing` 继续保留价格阅读上下文。

八份方案由 `#/works` 索引直达；当前没有正式作品，正常入口不展示空作品选项卡，历史`view=published`直达保留明确空态。静态对象/场合标签不可选；七案3组单选会更新当前含义与组合成果，品牌页保留独立方案控件，成长主题单选、场景最多3项且不足2项有提示，个性设置与摘要联动。此图解不生成、不上传、不持久保存，不写入两玩法草稿。品牌采用工行方案示例及独立选项，不再绑定旧brand-1；旧brand-1本身仍保留。退休无对应生成设置，高定不提供自助生成；这两类页面的方案选项仍可用于理解创作方向。方案主动作围绕项目咨询，通用体验是次级能力演示，不冒充该方案已上线生成模板；长方案增加可聚焦的内容跳转。

分类样片的筛选、展开及滚动按`business:category`保存，全库用`business:all`。分类入口自动展开对应原配置，退休分类不显示team职场主题，另有明确全库入口；不再继承无关分类状态。样品页返回合法同产品分类方案，无有效分类时回产品顶部。

### 2. 新体验中心：模板与自定义

`#/experience-center`在顶部直接切换两种玩法；各自内存草稿保存step、templateId、identity、sceneId、action、photo、authorized。模板固定身份/场景/行为；自定义须选择合法身份、场景及非空行为，行为建议写入同一可编辑文本框。两种玩法共享内容设定、准备素材、确认创作三步，切换与暂离保留各自草稿，刷新清空。

体验入口的来源由当前URL中的合法`returnTo`决定；全局入口不带来源，不继承先前品牌页面。两玩法切换通过`experiencePathFor`保留合法来源，返回和咨询均按该来源处理；具体白名单与旧`source=brand`兼容见[09第6节](09-apple-story-and-interactions-20261101.md#6-本轮交互检查发现与修复目标)。

新设定记录只有前端含义。照片选填、10MiB以内JPG/PNG/WebP且需解码；有图须授权，替换重置授权；异步候选的取消/释放、坏图替换、模式切换及离页保护独立实现。确认页可复制/手动复制配置，不含照片和Blob URL。真实生成按钮保持禁用，不创建任务、不上传、不写存储。详细字段与生命周期见[07本地改版](07-product-experience-local-20261030.md)。

### 3. 原有九主题配置

| 状态 | 显示与可用动作 | 继续条件 |
|---|---|---|
| 选择内容（step=0） | 三组单选按钮，`aria-pressed`标选中；每组只能保留一项 | 每组已有一个非空选择，才能到准备照片 |
| 准备照片（step=1） | 照片可选；选择、更换、移除；有有效照片才显示授权框 | 解码不在进行中，且无照片或有效照片已授权 |
| 确认信息（step=2） | 三组文字与可选照片预览；可直接“修改内容/修改照片”；复制配置 | 只能复制；“生成暂未开放”始终禁用，不创建任务 |

步骤条可以回跳；未完成内容时照片/确认按钮禁用，授权未确认或解码中不能到确认。步骤切换滚回顶部并聚焦该步标题，避免顶栏遮挡。编辑内容或照片时保留其他已填选择；有照片的配置复制时只附“已选、仅本机预览”状态，不含图像、Base64或Blob URL。

复制成功显示短暂状态；剪贴板拒绝或不支持时，打开只读文字摘要供手动复制，用户能关闭并返回配置。复制不代表生成、保存到服务器或发送咨询。

### 4. 原有配置的照片校验、授权与释放

| 项目 | 当前精确规则 |
|---|---|
| 文件类型 | MIME只接受`image/jpeg`、`image/png`、`image/webp`；input也设置相同accept |
| 大小 | 拒绝`file.size > 10 * 1024 * 1024`；恰好该字节数仍进入解码，不因大小自动拒绝 |
| 内容有效性 | Object URL交由`Image.decode()`读取，naturalWidth/naturalHeight必须非零；扩展名正确不足以认定有效 |
| 等待反馈 | 显示“正在检查照片…”，阻止进入确认；不调用上传API |
| 坏图或失败替换 | 报可访问错误提示；如果先前已有有效照片，保持旧照片及其原授权，不用失败候选替换它 |
| 有效替换 | 成功后回收旧有效Object URL，显示新图，并重置授权为false |
| 移除 | 取消待验证候选、释放候选和当前有效URL、清空文件input及授权 |
| 快速连续选择 | 校验序号保证最后一次选择生效；更早异步结果不能覆盖新照片 |
| 解码中离页 | 取消并回收待验证URL；先前有效照片可随同主题内存草稿保留 |
| 换主题/关闭应用 | 确认换主题或应用卸载时回收当前有效URL；刷新或关闭不恢复草稿 |

本机“照片使用授权”只保护本地预览路径，不自动覆盖未来上传、生成、公开展示或成片传播用途；真实处理前应按业务清单另行确认。

### 5. 原有配置的同主题暂离与换主题

原有九主题配置只保留**当前一个**主题的`ThemeDraft={step, choices, photo, authorized}`。同主题通过底部导航暂离后回来，恢复已有步骤、文字与有效照片；新标签页或刷新不会继承。

进入不同主题时，只要现有草稿有任何文字选择或照片，先打开“更换主题？”：取消保留原路由和完整草稿；确认才清空旧内容、释放旧照片并进入目标主题。普通hash链接、程序hash变化与原生前进/后退均经过保护；`history.state`中的`guangdangPosition`只用于历史游标，不保存业务草稿。

原有主题设置记录合法进入来源：从方案或具体样片页进入可返回来源；独立直链默认回原配置全库。浏览器原生返回按历史工作，换主题保护仍生效。新体验中心另按模式保留草稿，不占用这一个旧主题草稿。

### 6. 合作需求与本机摘要

`进入带来源的表单 → 填需求 → 整理需求摘要 → 复制/手动复制 → 返回修改或来源页`。表单只有本机行为，没有发送动作或成功受理回执。

| 字段名 | 必填与长度 | 当前行为 |
|---|---|---|
| `direction` | 必填 | 当前产品可选对应四方向，通用入口可选全部八方向；另有“尚未确定，想先了解” |
| `description` | 必填，最多2000字符 | 提交时trim；空白内容报告“请简单描述项目的目标和用途。” |
| `organization` | 选填，100字符 | 单位/项目名称 |
| `timing` | 选填，100字符 | 时间描述；当前不是严格日期组件 |
| `scope` | 选填，160字符 | 影像馆提示人数/场次，高定提示片长/画幅；不自动解释为合同范围 |
| `name` | 选填，50字符 | 联系人 |
| `contact` | 选填，100字符 | 任意联系方式文字；当前不强制手机号/邮箱格式，不要求留联系方式才能整理摘要 |

来自主题的表单携带合法产品、分类、themeId，以及当前内存草稿中的已选文字；照片不进入合作需求。参考主题与用户新选方向不匹配时，显示说明、将方向标为无效并禁用摘要；即使触发表单提交也不生成矛盾摘要。当前保留原主题和草稿，不自动改来源或清除主题；跨方向完整业务策略为B01待定。

需求内存键为`business:directionId:themeId`；相同键重新进入可恢复，换产品/方向/主题隔离。key不包含source或section，因此**相同产品/方向/主题、不同入口的表单可能复用同一草稿**，不要理解为每个入口独立。刷新清空。

摘要目前包含产品、可选参考主题与文字选择、方向、描述及非空选填项，结尾明确“尚未发送”。从完整方案进入时包含合法的具体参考方案名；改为其他方向后，页面明确取消不适用的参考方案，摘要同步移除。此规则只处理方案引用，不改变上述固定主题来源的不兼容方向保护。从全局合作选择器进入使用`source=chooser`，返回选择器；无段落的产品咨询默认回产品顶部。摘要在原生dialog内；复制失败改变按钮提示为手动复制，文本框可选择；返回修改关闭dialog并保留表单。

## 导航、位置与内存生命周期

| 状态 | 当前保存范围 | 暂离/返回 | 刷新/新标签 |
|---|---|---|---|
| 新体验草稿/照片 | 每种玩法各一份、应用根内存 | 切换玩法或暂离恢复，模板设定固定 | 清空 |
| 原主题草稿/有效照片 | 仅一个旧主题、应用根useRef | 同主题恢复；换主题确认后替换 | 清空 |
| 产品阅读位置 | business＋section（introduction/applications/experience/pricing） | 显式section定位目标；只有restore=1返回才恢复记录，无记录按段落定位 | 清空 |
| 样片库展开/位置 | business＋category；全库单列all | 同上下文恢复，分类相互隔离 | 清空 |
| 样片主题筛选 | `sampleViews[business:category].filter` | 分类内限定对应主题；全库保留自身筛选 | 回对应分类或all |
| 合作表单草稿 | business＋directionId＋themeId | 相同键恢复，其他键隔离 | 清空 |
| 方案页阅读位置 | 无专门记忆 | 重新进入通常从顶部；不是产品阅读位置记忆 | 无恢复 |
| 应用方案/正式作品分区与筛选 | URL中的合法product及view；根内存solutionViews按route保存滚动 | from=solutions与filter标记方案来源；咨询origin=solutions保留返回筛选；位置按同route恢复 | 内存位置清空；URL仍决定所选产品/分区 |
| 手动暂停动效 | 本次应用浏览 | 同一应用内切页保留；系统减少动态优先 | 重置到系统设置 |

业务草稿不写localStorage/sessionStorage，不进入分享URL。`#/cooperate`的来源查询参数可以分享，输入内容和照片不会跟随。顶部“复制当前页面链接”复制完整URL（站点version查询和hash均保留）；失败时显示需手动复制的地址。

页面路由变化先滚回顶部并聚焦main，随后产品/样片组件可按自身记忆恢复位置；不能据这一全局动作断言所有返回都丢位置。应用接管`history.scrollRestoration`并在卸载时恢复旧设置。

## 图库、媒体与错误恢复

- 当前方案索引由八份完整应用方案构成，按产品筛选；方案配图与真实作品分开。品牌卡片及专页使用独立深圳参考图，原工行海报仅保留为项目资料，网页没有海报或查看原图链接。旧图库的瀑布流/每次6项规则不再作为本轮方案索引契约。
- 当前真实作品、案例与样片为空，显示“待上架/制作中”，不能用概念图片加假播放替代。未来条目展示要求`status === 'published'`且`displayAuthorized === true`；样片还要求视频类型。前端布尔标记不替代授权证明/后台审核。
- 图像懒加载为默认，首页两卡与部分主视觉eager；`-1920.webp`提供800/1920 srcSet。读取失败显示带语义替代图块，保留页面导航。视频失败显示可恢复的说明；不自动播放音频。
- 原生dialog支持Escape、关闭按钮和遮罩点击；关闭后恢复触发控件焦点，目标不存在则回main。切换主题的对话框关闭等同取消，不清空草稿。
- 畸形URI不抛出空白根节点；非法路径显示“暂时没有这个页面”及返回首页。无网络列表接口，所以当前静态空态/图像错误行为不是未来列表超时/分页契约。

## 响应式、视觉与可访问性基线

当前H5面向手机。测试基线为320/360/375/390/430手机宽度，以及768/1440布局；它们是浏览器模拟与布局检查，不是真实iOS/Android、微信WebView或读屏验收。

- 首页保持短定义和两个产品入口；两产品名称与有效动作可发现，允许自然纵向滚动。旧390×844几何数据仅为10月30日记录，本轮观测见最新回执，不能为了旧“一屏”指标缩小文字。
- 手机使用固定底部四导航，桌面使用顶部主导航，统一为首页/应用方案/能力体验/合作咨询；旧mine路由不占主入口。产品页和方案页的内容跳转保留定位间距，避免标题被固定栏遮挡；断点以本轮样式为准。
- 新产品/方案正文以16px为基准；标题、辅助标签和操作按用途区分。商品/方案图标明概念/参考/成果示意。不要把所有文字压成相同字号，也不承诺所有图片都可无裁切铺满任意比例。
- 系统`prefers-reduced-motion`优先；手动暂停停止连续动效，系统减少动态启用时对应按钮禁用并解释状态；暂停/减少动态时锚点即时定位。
- 短视口聚焦合作输入会避让固定栏，仍需真机软键盘验证。表单主要输入16px、按钮有明确焦点/当前/选择语义，存在跳到main入口。
- CSS按[`main.tsx`](../main.tsx)顺序叠加；既有主题、体验和`b2b-refinement.css`之后，最后加载本轮`apple-editorial.css`，提供官网式留白、图文分段、少量卡片与配置图解控件。具体顺序以入口为准，保留原有配置表单、弹窗与深浅色语义；不通过重挂组件实现外观变化。
