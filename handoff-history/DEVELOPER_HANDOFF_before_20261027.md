# AI影像馆前端开发交接说明

## 交付定位

这是移动端高保真交互原型源码，用于前端开发还原页面、状态与交互。当前所有数据和任务状态均为前端模拟，不包含真实用户数据、后台接口、数据库、鉴权、视频生成、下载或分享服务。

## 技术栈与启动

- React + TypeScript + Vite
- Node.js 20 或以上

```bash
npm install
npm run build
npm test
npm run test:ui
```

开发预览：

```bash
npm run dev
```

## 代码入口

- `main.tsx`：应用挂载入口
- `app/AiImageHall.tsx`：页面、产品状态、交互与演示数据
- `app/globals.css`：视觉系统、玻璃拟态、响应式与动效
- `public/images/v4/`：九个记忆场景图片
- `scripts/postbuild.mjs`：GitHub Pages 深层路径构建
- `tests/`：静态与移动端关键链路测试

## 产品页面

1. 作品展示：卡片堆叠浏览，点击后进入沉浸式作品详情。
2. 视频生成：上传素材、选择记忆、提交生成三个阶段。
3. 我的：创作任务、作品列表、任务详情与作品详情。
4. 分享作品：视频直接嵌入动态海报模板，支持页内播放、复制链接与唤起分享。

分享页深层路径为 `/share/demo-share/`。分享入口来自作品详情、生成结果和“我的作品”。

## 接口接入建议

开发时把 `AiImageHall.tsx` 中的静态数组和本地状态替换为业务接口及路由状态：

- 用户与登录状态
- 人脸照片、人物形象上传及本人核验
- 记忆组合配置
- 生成任务创建、管理员确认、进度查询、失败重试
- 作品列表、公开审核、删除和下载
- 分享链接、视频地址、动态海报数据与系统分享能力

动态海报当前由前端 DOM 与模拟视频画面组合展示。正式开发需要把成品视频地址直接嵌入海报模板，并用 Web Share API、微信 JS-SDK 或原生容器唤起真实分享；复制链接应使用后端签发的有效分享地址。若还需输出静态封面，可另用 Canvas 或服务端渲染生成，但不应替代动态海报中的视频播放。

## 必须保留的产品边界

- 不包含声音选择、录音、声音授权或声音匹配。
- 选择记忆固定三层，每层三个选项、每层只能选择一个。
- 用户素材授权位于上传素材步骤末尾。
- 真实生成必须经过 Mac 管理员确认。
- 分享页和公开作品不得展示人脸原图、核验资料等隐私素材。
- “状态预览”“填充测试素材”等原型调试入口不得进入正式产品。

## 设计与适配

- 作品展示与作品详情使用深色高级影像风格。
- 生成与“我的”使用冷淡色背景和透明玻璃组件。
- 移动端操作目标不小于 44 px，并保留安全区适配、键盘焦点和减少动态效果支持。
- 桌面端以 390 × 844 的移动设备画框展示，正式 H5 可移除外层设备画框限制。

## 原型与真实产品的差异

原型中的上传、核验、生成进度、下载、复制链接、唤起分享、公开审核和删除均为交互演示。正式开发需要补充接口错误、超时、权限、幂等、断点恢复、文件格式与大小校验，并按照产品后端协议实现。
