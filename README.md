# 咣当 AI影像 · 改版展示版

依据2026年10月15日《咣当 AI影像小程序需求文档》更新。移动端优先，同时适配桌面，使用已有公开 GitHub Pages 渠道。

## 当前功能

- 咣当统一品牌与双业务首页；AI影像馆、高定AI影像各四类方向。
- 分类筛选、示例主题详情、相关方向跳转及可分享的 hash 路由。
- 模板流程预览：选择内容、照片本机预览、授权校验与确认摘要；不会调用生成接口。
- 独立双列移动端作品库，业务/分类筛选、分页、图片详情与空状态。
- 真实案例、作品与模板分别建模；已授权已发布作品可配置图片/视频播放。
- 商务需求摘要的预览与复制；不发送、不上传、不保存填写内容。
- 我的基础页、加载失败提示、未开放状态、手机底部安全区与键盘可访问性。

## 业务边界

本版本是可分享的前端改版展示版，不是已经完成后端联调的小程序。需求参考照片与布局示意均有标识，不作为实际客户案例或生成效果证明。真实案例与已发布作品初始为空。登录、支付、订单、统一任务记录、真实生成及咨询承接系统尚未接入。

## 运行与验证

```sh
npm ci
npm run build
npm exec vite preview -- --host 127.0.0.1 --port 4187
npm test
```

`npm test` 构建后自动启动4188端口测试服务，使用本机Google Chrome检查375、390、430、768、1440宽度与主要用户路径。Chrome路径可在 `tests/guangdang-ui.mjs` 调整。

GitHub Pages从main分支 `/docs` 发布。源码入口为 `app/Guangdang.tsx`；数据配置为 `app/guangdang-data.ts`；样式为 `app/guangdang.css`。旧版 `app/AiImageHall.tsx` 与原样式保留用于历史参考，不再由当前入口加载。

更多配置说明见 [GUANGDANG_HANDOFF.md](./GUANGDANG_HANDOFF.md)。
