# 咣当 AI影像 · 改版展示版

移动端优先的双产品展示与体验原型，沿用咣当彩色 Logo、“属于你的AI片场”口号与深色科技风格，通过原有 GitHub Pages 渠道分享。

## 当前版本：2026年10月22日 · B端首次访问优化

本轮分享入口使用 `version=20261022-2`；公开可用性以对应提交的部署结果与匿名验证为准。

面向第一次进入的品牌方、政企单位和机构客户，先明确两个产品的用途，再通过体验、介绍与应用建立合作意向。首页继续保留两个产品入口；AI影像馆和高定AI影像沿用相同的三部分结构：**产品体验、产品介绍、商业应用**。其他内容框架保持不变，手机和电脑主导航均为“首页、主题体验、商务合作、我”；右上角星形入口继续隐藏。

- **AI影像馆体验**：九个主题改用卡片网格，手机两列、桌面三列，封面统一16:9。五项筛选为“全部主题、城市品牌、活动节庆、职场团队、校园青春”；点击整张卡片直接进入对应配置。返回列表保留筛选、位置和最近使用主题。
- **高定AI影像体验**：四个精品创作方向使用紧凑卡片，手机两列、桌面四列，按企业故事、城市与历史、人物故事、家庭记忆排列，优先呈现机构客户常用方向。当前仍标记“样品待上架”，不设置伪播放；同类需求入口进入已选好方向的商务需求表单。只有已授权、已发布的真实视频才会出现播放器。此顺序只用于体验卡片，商业应用仍沿用用户参考图的顺序。
- **产品介绍**：依据汇报PPT第7、12、15、20页，围绕“让更多人参与传播”和“讲好独特故事”细化采购视角。每个产品提供4项具体合作内容、2项合作对象或角色、4步合作流程、3项准备资料，以及数量、时点、片长、画幅或服务范围的项目约定边界；不使用未核实的价格、周期、效率与效果承诺。
- **商业应用**：AI影像馆四类为品牌推广与主题传播、活动互动与用户体验、企业文化与员工关怀、校园与社群纪念；高定四类为人物故事、家庭记忆、企业故事、城市与历史。每类详情直接展示客群、应用场景、价值和可拓展方向；各保留默认收起的四项“产品亮点和优势”。影像馆关联对应主题，高定直达同类需求整理。
- **分区与返回**：三个分区有独立URL，支持触摸、鼠标和键盘切换；使用稳定的ARIA tab/panel关联。首页重新进入产品时保留本次浏览所选分区；主导航“主题体验”明确进入体验分区。浏览器前进、后退及页面返回恢复对应分区与滚动位置。
- **配置流程**：仍为“选择内容—准备照片—确认信息”，每主题保留独立选项。首步增加“将主题用于项目”，末步提供“整理合作需求”，将体验主题和已选文字配置带入合作需求。照片可选，仅在本机临时预览；有照片需授权，更换照片需重新授权。支持直接编辑、文字配置复制、复制受限时手动复制，以及更换主题前的草稿保护。
- **合作路径**：产品顶部、介绍末尾、商业应用详情与主题配置均有合作入口，通过 `product`、`direction`、`theme`、`source` 与 `section` 保留来源上下文，可返回原产品分区、应用详情或主题。具体产品只提供该产品的4个方向，通用商务合作保留8个方向；旧 `direction` 链接兼容。表单增加选填的单位／项目、计划时间、规模与交付要求。
- **文案**：缩短标题、行动语与状态提示，保留必要的生成、样品、账户与咨询状态。原 Logo、配色、四项导航和其他页面框架不作扩展。

## 内容与业务边界

本版本是前端展示原型。真实生成、账户、支付、订单及正式咨询承接尚未接入；不会上传照片或创建生成任务。高定样品继续待上架，主题配图和参考图片均不作为真实客户案例或生成结果。

只在浏览器内存中保留当前一个主题草稿、产品分区及浏览位置；刷新或关闭后清空，不写入localStorage/sessionStorage。更换主题先确认，有照片时确认后释放临时Object URL。商务表单的 `inquiryDrafts` 按产品、方向与主题隔离，暂离后返回恢复，刷新或关闭后清空。姓名、联系方式、单位／项目、计划时间、规模与交付要求均选填；需求摘要含产品、参考主题与已选文字，不含照片或Blob URL。摘要明确尚未发送，支持复制和手动复制，不上传、不持久保存。

真实咨询渠道尚未接入，目前销售转化止于需求整理与复制；不表示已受理咨询、报价、订单或购买，也不承诺传播效果和投资回报。

既有已发布案例的视频展示能力保留，当前真实案例集合仍为空。作品库继续保留“主题灵感／真实作品”筛选、4:3等高图片网格、分类、分页、图片详情与真实作品空状态；“我”保留访客和未开放账户状态。东门历史资料原文件及来源记录保留，当前产品页不引用。

## 运行与验证

```sh
npm ci
npm run build
npm exec vite preview -- --host 127.0.0.1 --port 4187
```

自动检查：

```sh
npm test
npm run test:ui
npm run test:mobile
npm run test:journey
```

`npm test` 构建后依次运行三套浏览器回归，测试会按需启动本机预览服务；依赖本机Google Chrome。各测试支持 `PREVIEW_URL` 指向已部署页面。单独执行UI或journey测试前，应先构建最新代码。

- `tests/guangdang-ui.mjs`：检查六档宽度、首页一屏、四导航、三分区切换与键盘操作、九主题筛选和直达、八类商业应用、样品空态、作品库及图片降级；新增B端介绍内容、紧凑高定卡片与合作入口检查。
- `tests/mobile-navigation.mjs`：检查手机列表返回、筛选与滚动恢复、步骤定位、照片授权和URL回收、刷新清空、无上传请求及生成禁用。
- `tests/product-journey.mjs`：检查可选照片、直接编辑、草稿保护、复制成功与手动复制；新增产品／方向／主题上下文、限定方向、合作草稿隔离及恢复、返回来源、选填项目资料与需求未发送检查。既有照片、原生返回和无上传保护继续保留。

本轮表单输入字号为16px，placeholder为14px；验证需检查手机输入不触发异常放大、文字不溢出、按钮与键盘状态正常。以上为测试覆盖范围，不表示本轮检查已通过。

代码检查通过不等于线上发布。公开交付需等待GitHub Pages部署成功，再通过匿名手机页面验证当前版本；用户验收单独确认。

GitHub Pages从main分支 `/docs` 发布。源码入口为 `app/Guangdang.tsx`；数据为 `app/guangdang-data.ts`；样式为 `app/guangdang.css`、`app/cyber.css`、`app/mobile-first.css` 和最后加载的 `app/product-pages.css`；后者负责本轮产品分区与主题网格。旧版 `app/AiImageHall.tsx` 与原样式只作历史参考，不由当前入口加载。

### 历史：2026年10月21日“直接体验”补充

用户确认在原型内直达配置，不接入真实生成。九个主题各有独立URL、标题、配图与配置选项，按钮统一“立即体验”。`themeConfigurations` 和 `configurationOptions` 配置主题信息与交互选项，`experiencePath` 统一生成直达链接。详情、作品入口及分享链接保持对应主题，旧分类体验URL兼容默认配置，未知主题显示原有404提示。
