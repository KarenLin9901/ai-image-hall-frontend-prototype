# 咣当 AI影像 · 产品展示版

## 当前版本：2026-10-23 · A光场风格

面向品牌、企业、政企单位与机构客户。B端采购并发起项目，参与者使用主题互动产品；高定业务由企业与机构委托，围绕人物、家庭、企业与城市题材创作专属影片。

分享入口：`https://karenlin9901.github.io/ai-image-hall-frontend-prototype/?version=20261023-2#/`。公开可用性以本轮GitHub Pages部署及匿名页面核验为准。

### 视觉与文案

用户已选定A「光场实验室」。首页采用银色透镜、双环带与悬浮画框；全站统一近黑、银色细线和蓝粉微光。原小程序彩色Logo形态保留，调整字标组合与比例。首页主标题按最新标注图改为“你想如何创作一部AI影像？”，引导语为“互动生成，还是专属创作？选择适合你的影像服务。”，口号为“属于你的AI片场”。两入口说明分别为“模板化互动影像产品”“精品AI影像创作服务”。产品内部继续按B端采购与发起、参与者体验阐述。

动效包含主视觉触摸倾斜、慢速光环、品牌微光、产品图片光泽、短页面转场和内容进入。顶部可暂停／恢复动效；遵循系统减少动态效果设置。没有强制开场、自动音频或等待动画。小屏主视觉整体缩放，优先保证两个产品入口可达。

### 产品内容与路径

依据《修改文稿3.docx》和后续确认，两产品采用同一连续长页：服务介绍（含产品简介、特点优势）、场景启发、立即体验。四项导航在同页定位并高亮当前位置，不生成多余页面层级。简介保留B端用途、合作角色、三组优势，以及按需展开的合作内容、流程与准备资料。

- AI影像馆：品牌推广与主题传播、活动互动与用户体验、企业文化与员工关怀、校园与社群纪念。
- 高定AI影像：人物故事、家庭记忆、企业故事、城市与历史。
- 每类场景有独立应用示例、三步制作过程、场景参考图和可拓展方向。示例不作为已交付客户案例。
- “立即体验”和场景“查看样片”进入对应样片页。目前明确“样片制作中”，不使用配图冒充可播放作品。
- 九个既有主题设置保留在影像馆样片页的“主题配置预览”中，点击主题直达对应设置；旧URL保持兼容。
- 主导航为“首页、案例分享、商务合作、我”。案例分享保留主题灵感和真实作品区分，采用原图比例瀑布流；真实作品仍待上架。星形关于入口继续隐藏。

### 真实业务边界

这是前端产品展示版。真实生成、账户、支付、订单和正式咨询服务尚未接入；不上传照片、不创建任务、不代发需求。样片与真实案例集合为空，只有已授权且已发布的视频才会出现播放器。

主题照片仅在本机临时预览；有照片需确认授权，更换照片重新授权。只保留当前主题的内存草稿，更换主题有确认保护，刷新或关闭清空。商务需求按产品、方向和主题隔离；摘要支持复制及手动复制，明确尚未发送，不含照片和Blob URL，不写localStorage/sessionStorage。

### 运行与核验

```sh
npm ci
npm run build
npm exec vite preview -- --host 127.0.0.1 --port 4193
npm test
```

`npm test`构建后依次运行四套真实浏览器检查；依赖本机Google Chrome。各套支持`PREVIEW_URL`指向部署页面，最后一套为`tests/lightfield-visual.mjs`，覆盖默认动效与暂停、系统减少动态、手机遮挡和实际复制分享链接。前三套保留九主题、照片授权与回收、原生返回守卫、合作上下文、草稿隔离、复制降级和无上传检查。

手机检查覆盖320/360/375/390/430宽度，另检查768/1440电脑布局。图片包含高清800/1920 WebP和加载失败替代；作品保持自然比例。代码检查、部署成功、公开页面核验与用户验收分别记录。

### 源码与发布

当前入口为`app/Guangdang.tsx`；业务数据为`app/guangdang-data.ts`。`app/LightfieldVisual.tsx`与`lightfield-visual.css`负责主页光场，最后导入的`lightfield.css`统一全站视觉。`editorial-pages.css`提供文稿3页面结构；较早CSS保留兼容配置、作品和表单。历史`AiImageHall.tsx`不由当前入口加载。

GitHub Pages使用main分支`/docs`发布。正常快进推送后，等待Pages构建成功，核对匿名HTML引用的JS/CSS与本地构建一致，再验证公开手机路径。更多路由与接口边界见`GUANGDANG_HANDOFF.md`。

产品定位来自既有汇报PPT、用户提供的两张分类图与修改文稿。视觉参考Active Theory、Resn及Dogstudio官方站点的互动表达，未复制其代码或媒体资产；不移用客户标识、数据、服务承诺、价格或生成效率。

### 历史：2026年10月21日“直接体验”补充

用户确认在原型内直达配置，不接入真实生成。九个主题各有独立URL、标题、配图与配置选项，按钮统一“立即体验”。`themeConfigurations` 和 `configurationOptions` 配置主题信息与交互选项，`experiencePath` 统一生成直达链接。详情、作品入口及分享链接保持对应主题，旧分类体验URL兼容默认配置，未知主题显示原有404提示。

配置页直接显示选择项，随后选择本机照片并确认信息。真实生成状态始终标为“生成未开放”，最终按钮禁用，不上传照片、不创建任务。同一主题暂离再返回会恢复进度；选择其他主题、替换照片或刷新时清除对应临时照片，不写入持久存储。
