# 深圳AI影像馆高保真前端原型

移动端优先的静态高保真版本，以《我在深圳的生活 be like》V6脚本为内容基线：固定C01开场，C02居住、C03续命补给、C04精神打卡地各三选一，组成精确30秒视频。

原型包含作品瀑布流、三步视频生成、Mac管理员确认门禁、任务与作品详情、生成同款，以及加载、失败、取消、重试和公开审核等可点击状态。

项目仅包含前端界面、模拟状态和原创场景效果图，不包含用户数据、真实生成接口或后台服务。

## 本地构建

```bash
npm install
npm run build
npm test
npm run test:ui
```

GitHub Pages 从 `main` 分支的 `/docs` 目录发布。
