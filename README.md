### 历史：2026年10月21日“直接体验”补充

用户确认在原型内直达配置，不接入真实生成。九个主题各有独立URL、标题、配图与配置选项，按钮统一“立即体验”。`themeConfigurations` 和 `configurationOptions` 配置主题信息与交互选项，`experiencePath` 统一生成直达链接。详情、作品入口及分享链接保持对应主题，旧分类体验URL兼容默认配置，未知主题显示原有404提示。

配置页直接显示选择项，随后选择本机照片并确认信息。真实生成状态始终标为“生成未开放”，最终按钮禁用，不上传照片、不创建任务。同一主题暂离再返回会恢复进度；选择其他主题、替换照片或刷新时清除对应临时照片，不写入持久存储。

### 历史：2026年10月21日手机全流程复查

手机端九主题完整检查覆盖360×640、375×667、390×844、430×932，共36次“选择内容—照片授权—确认—修改—返回”流程；另补查320小屏的图片、弹窗和真实触屏横滑。

修复三项返回问题：回到AI影像馆时恢复原主题卡；每次路由与步骤切换后滚回顶部，避免标题/步骤条被固定顶栏覆盖；当前主题的配置与照片可在临时切页后恢复。只保留当前一个主题的内存草稿，选择其他主题或刷新页面清空；换照片重新授权并释放旧URL，不上传、不调用真实生成。

`npm test` 已包含新的 `tests/mobile-navigation.mjs` 回归，默认使用4189预览服务，检查页面/浏览器返回、照片回收、刷新清空、无上传请求和生成禁用。可单独运行 `npm run test:mobile`，或通过 `PREVIEW_URL` 对已部署页面验证。
