# 咣当 AI影像 · 改版展示版

依据2026年10月15日《咣当 AI影像小程序需求文档》、10月17日品牌视觉反馈及10月20日手机端反馈更新。移动端优先，同时适配桌面，使用已有公开 GitHub Pages 渠道。

## 2026年10月17日更新

- 沿用项目历史彩色咣当Logo，口号统一为“属于你的AI片场”。
- 深色科技视觉、冷蓝与紫色光效，移除外部字体依赖。
- 使用用户压缩包高清照片，提供800/1920双尺寸WebP，保留原始照片比例。
- 八类详情各增加四项产品亮点和优势，分类卡片同时展示摘要。
- 图片来源与Logo校验记录见 `ASSET_SOURCES_20261017.json`。

## 2026年10月18日历史资料更新

- 从东门媒资图集21张图片中挑选5张，替换“城市与历史”封面和关联位置。
- 详情页展示东门标识、钟景、街区全景、牌坊和步行街人流，支持放大与翻页。
- 原资料未标注年代，按历史资料展示；不作为AI生成作品或客户成片案例。

## 2026年10月20日手机端精简

- 首页以“今天，想拍点什么？”引导选择，只保留口号与两个业务入口；常见手机尺寸可一屏展示。
- 二级页突出“立即体验”，主题与样品卡片支持原生横滑、左右按钮和键盘切换。
- “产品简介”默认收起，展开查看定位、亮点与链路；“场景启发”进入分类，再进入具体阐释。
- 各场景的优势、适用对象和链路按需展开；东门五张历史资料保留在“东门历史影像”中。
- 移除装饰性英文、小字标签、重复介绍和页脚，保留必要状态信息并提高可读字号。
- 高定目前没有已确认的可播放样片，使用明确的“样品待上架”状态。确认公开视频后，配置 `publishedWorks` 即可使用现有播放器。

## 当前功能

- 咣当统一品牌与双业务首页；AI影像馆、高定AI影像各四类方向。
- 场景分类、示例主题详情、相关方向跳转及可分享的 hash 路由。
- 模板流程预览：选择内容、照片本机预览、授权校验与确认摘要；不会调用生成接口。
- 独立双列移动端作品库，业务/分类筛选、分页、图片详情与空状态。
- 真实案例、作品与模板分别建模；已授权已发布作品可配置图片/视频播放。
- 商务需求摘要的预览与复制；不发送、不上传、不保存填写内容。
- 我的基础页、加载失败提示、未开放状态、手机底部安全区与键盘可访问性。

## 业务边界

本版本是可分享的前端改版展示版，不是已经完成后端联调的小程序。需求参考照片与布局示意均有标识，不作为实际客户案例或生成效果证明。真实案例与已发布作品初始为空。登录、支付、订单、统一任务记录、真实生成及咨询承接系统尚未接入。

## 运行与验证

```sh
npm ci
npm run build
npm exec vite preview -- --host 127.0.0.1 --port 4187
npm test
```

`npm test` 构建后自动启动4188端口测试服务，使用本机Google Chrome检查360、375、390、430、768、1440宽度与主要用户路径；另外检查360×640、375×667、390×844、430×932首页一屏展示。Chrome路径可在 `tests/guangdang-ui.mjs` 调整。

GitHub Pages从main分支 `/docs` 发布。源码入口为 `app/Guangdang.tsx`；数据配置为 `app/guangdang-data.ts`；样式为 `app/guangdang.css`、`app/cyber.css` 和 `app/mobile-first.css`。旧版 `app/AiImageHall.tsx` 与原样式保留用于历史参考，不再由当前入口加载。

更多配置说明见 [GUANGDANG_HANDOFF.md](./GUANGDANG_HANDOFF.md)。
