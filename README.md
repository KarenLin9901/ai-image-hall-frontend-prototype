## 历史变更记录

以下记录描述各轮当时行为，保留追溯。旧一屏首页、双产品轮播、简介/优势两折叠结构和旧导航排列均不作为现状说明；现状以本文件当前版本说明及源码为准。

### 历史：2026年10月21日《1021修改文档》

- 手机底部导航与电脑主菜单在“商务合作”后恢复“我”，进入既有个人页并正确高亮。
- AI影像馆与高定AI影像均把原三条优势简述移入“产品简介”，保留定位与默认收起。
- 独立“产品优势”改为四组标题与详细说明，沿用子品牌详情的分隔线布局；不再只显示三条短句。

### 历史：2026年10月21日产品与交互优化

- 首页仍一屏双入口，行动语区分“选主题体验”和“专属故事定制”；高定主区使用“定制方向”。
- AI影像馆保留九主题横滑，新增“全部主题”缩略图选择，直接进入对应配置。
- 九主题明确为单人参与的原型配置。团队/校园选项改为个人视角；真实多人故事、真实品牌素材进入高定需求方向。
- 照片是可选的本机预览，不再统一收集性别。选择照片后仍需确认使用授权，更换照片重新授权；可明确移除照片。
- 确认页分别编辑故事内容与照片，步骤支持回跳，已填资料保留；完成后可复制文字配置，复制受限时提供手动复制文本，不包含照片或Blob URL。
- 进入其他主题前，如已有选择或照片，先确认是否清空；取消保留旧草稿，确认后释放临时照片。刷新仍清空，不写浏览器持久存储。
- 底部主导航为“首页、主题体验、商务合作”；“影像作品示意”和“我的（待开放）”保留在关于原型的次级入口，旧URL兼容。
- “咨询定制”统一为“整理定制需求”。需求摘要支持不填姓名/联系方式、复制与返回修改，明确尚未发送及咨询渠道待开放。
- 真实生成、账户与咨询承接未接入；高定样品继续待上架，不用场景配图代替真实成片。

### 历史：2026年10月21日“直接体验”补充

用户确认在原型内直达配置，不接入真实生成。九个主题各有独立URL、标题、配图与配置选项，按钮统一“立即体验”。`themeConfigurations` 和 `configurationOptions` 配置主题信息与交互选项，`experiencePath` 统一生成直达链接。详情、作品入口及分享链接保持对应主题，旧分类体验URL兼容默认配置，未知主题显示原有404提示。

配置页直接显示选择项，随后选择本机照片并确认信息。真实生成状态始终标为“生成未开放”，最终按钮禁用，不上传照片、不创建任务。同一主题暂离再返回会恢复进度；选择其他主题、替换照片或刷新时清除对应临时照片，不写入持久存储。

### 历史：2026年10月21日手机全流程复查

手机端九主题完整检查覆盖360×640、375×667、390×844、430×932，共36次“选择内容—照片授权—确认—修改—返回”流程；另补查320小屏的图片、弹窗和真实触屏横滑。

修复三项返回问题：回到AI影像馆时恢复原主题卡；每次路由与步骤切换后滚回顶部，避免标题/步骤条被固定顶栏覆盖；当前主题的配置与照片可在临时切页后恢复。只保留当前一个主题的内存草稿，选择其他主题或刷新页面清空；换照片重新授权并释放旧URL，不上传、不调用真实生成。

`npm test` 已包含新的 `tests/mobile-navigation.mjs` 回归，默认使用4189预览服务，检查页面/浏览器返回、照片回收、刷新清空、无上传请求和生成禁用。可单独运行 `npm run test:mobile`，或通过 `PREVIEW_URL` 对已部署页面验证。

`tests/product-journey.mjs` 覆盖本轮产品流程：九主题总览、可选照片、直接编辑、草稿确认、复制成功/降级和无联系方式需求整理。`npm run test:journey` 可单独运行，三套浏览器测试均支持 `PREVIEW_URL` 验证已部署版本。
